# SysDeck
### Мониторинг ИБП Ippon и компьютера с сайтом-дашбордом для ПК и телефона
### Описание:
SysDeck следит за бесперебойником Ippon (разработан для Ippon Back Basic 650 Euro, протокол Megatec по USB), пишет историю в базу и показывает всё на сайте: напряжение сети, нагрузку, аккумулятор, события. Там же - параметры компьютера: процессор по потокам и частоты ядер, видеокарта, память, диски и их здоровье, сеть, процессы, температуры, напряжения и вентиляторы (через LibreHardwareMonitor).

При пропаже сети SysDeck шлёт сообщение в Telegram и может перевести ПК в гибернацию. Сайт работает на ПК и телефоне, есть вход по паролю (для доступа через интернет), английский и русский язык, темы оформления.

Проект портативный: нужен только Python 3.11 или новее. Недостающие библиотеки ставятся сами при первом запуске, LibreHardwareMonitor лежит в папке проекта.

#

### Краткая инструкция по использованию:

#### 1. Как запустить?

Двойной щелчок по ```SysDeck.pyw``` (или ```SysDeck.bat``` - он запустит его и сразу закроется).</br>
Windows один раз спросит права администратора - они нужны LibreHardwareMonitor для датчиков.

SysDeck живёт в трее (значок с молнией):
- **Синий** - всё работает.
- **Жёлтый** - ИБП работает от батареи.
- **Серый** - остановлен.

Щелчок по значку открывает окно управления. Крестик окна прячет его обратно в трей.</br>
Правая кнопка по значку: открыть сайт, запустить / остановить, перезапустить, выход (останавливает всё).

#### 2. Где сайт?

- ```http://127.0.0.1:8080``` - На этом ПК.
- ```http://192.168.x.x:8080``` - С телефона и других устройств в локальной сети (точные адреса - на вкладке **Обзор** в окне SysDeck).

Для доступа извне локальной сети нужен проброс порта 8080 или туннель (например, Cloudflare Tunnel). В этом случае обязательно включите вход по паролю!

#### 3. Как включить автозапуск?

В окне SysDeck, вкладка **Обзор**, флажок **Запускать SysDeck вместе с Windows** (или пункт **Автозапуск с Windows** в меню значка в трее). Запуск идёт через Планировщик с правами администратора, без запроса UAC.

#

### Окно управления

| Вкладка | Что там |
| --- | --- |
| Обзор | Состояние сервиса, автозапуск, ИБП, LibreHardwareMonitor и сайта, адреса сайта по сетевым адаптерам, последние события. |
| Доступ | Вход по паролю вкл/выкл, пароль, сколько дней помнить вход, вход из домашней сети без пароля, завершить все сессии, порт сайта. |
| Компоненты | ИБП и LibreHardwareMonitor вкл/выкл, токен и чат Telegram (с кнопкой проверки). |
| ИБП | VID/PID устройства, пауза опроса, адрес и порт сервера данных, гибернация и через сколько секунд, запись на диск, сколько дней хранить историю. |
| Данные | Размеры файлов, очистка истории и журнала, сброс настроек. |
| Журнал | Весь журнал в реальном времени. |

#

### Структура проекта

#### 1. Файлы и папки
- SysDeck/</br>
  | File/Folder | Description |
  | --- | --- |
  | data/ | Папка со всеми данными: настройки, история, журнал. Появится после первого запуска. |
  | LibreHardwareMonitor/ | Программа для датчиков (температуры, напряжения, частоты, S.M.A.R.T.). Запускается скрыто вместе с SysDeck. |
  | web/ | Файлы сайта: ```index.html```, ```login.html```, ```app.js```, ```i18n.js``` (переводы), ```style.css```. |
  | SysDeck.pyw | Лаунчер: окно управления и значок в трее. Он же запускает сервис (ИБП + сайт) и LibreHardwareMonitor и перезапускает упавшее. |
  | SysDeck.bat | Запускает ```SysDeck.pyw``` без окна консоли и сразу закрывается. |
  | ippon_ups.py | Работа с ИБП: опрос, Telegram, гибернация, история и сервер данных. Можно запускать отдельно: ```python ippon_ups.py```. |
  | web_server.py | Сайт и мониторинг ПК. Можно запускать отдельно: ```python web_server.py```. |
  | requirements.txt | Нужные библиотеки Python (ставятся сами). |

#### 2. Папка данных
Любой из этих файлов можно удалить - при следующем запуске он создастся заново с настройками по умолчанию. Испорченный JSON откладывается рядом как ```*.broken```.
- data/</br>
  | File | Description |
  | --- | --- |
  | sysdeck.db | Вся история: ИБП, ПК, датчики, события. Одна база SQLite (```-wal``` и ```-shm``` - её служебные файлы). |
  | sysdeck.log | Единый журнал всего (лаунчер, ИБП, сайт). Больше 2 МБ - откладывается в ```sysdeck.old.log```. |
  | sysdeck.json | Настройки сайта: порт, вход, хеш пароля, срок сессии, что запускать. |
  | ups.json | Настройки ИБП: VID/PID, опрос, гибернация, порт сервера данных, хранение истории. |
  | tgbot.json | Токен и чат Telegram. Пусто - бот выключен, сообщения только в журнал. |
  | session.key | Ключ сессий сайта. Удалить - значит выйти на всех устройствах. |

Не отдавайте никому ```tgbot.json``` и ```sysdeck.json```!

#

### Перенос на другой ПК
Скопируйте папку целиком (без ```data/```, если история и настройки не нужны) и включите автозапуск заново.</br>
LibreHardwareMonitor 0.9.6 использует драйвер PawnIO: если его нет, LibreHardwareMonitor при первом запуске сам предложит его поставить.
